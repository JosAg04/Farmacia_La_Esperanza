 ================================
       CARPETA PUBLIC/VIDEO
 ================================

Esta carpeta fue creada para contener los videos del sitio, gifs o distintos formatos de videos usados en la pagina. 

-Formatos para usar: .mp4, preferiblemente comnprimido para que pese poco y no se tarde en cargar.
-Un ejemplo de su uso en un HTML seria: <video src="../../video/algo.mp4" controls>
-El atributo "controls" sirve para que el usuario tenga control sobre el video, para pausar, adelantar o reproducir.
