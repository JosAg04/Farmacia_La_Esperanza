       CARPETA PUBLIC/CSS
 ================================

Esta carpeta fue creada para contener los estilos en css para las diferentes paginas HTML del sitio, tanto publicas como de admininistracion.

-Aqui solo se guardan los css (hojas de estilo)
-Hay un archivo GLOBAL conectado a todas las paginas con los estilos compartidos entre ellas.
-Los HTML van en views/ y se enlazan con rutas relativas
-Los nombres de los archivos van en minisculas sin espacios,relacionados con su pagina HTML
-Un archivo por pantalla o componente.
