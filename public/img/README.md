 ================================
       CARPETA PUBLIC/IMG
 ================================

Esta carpeta fue creada para contener las imagenes del sitio, logos, iconos, fotos de productos, fondos, etc.

-Formatos usados: svg para logos e iconos, webp o jpg para fotos y png cuando se necesite transparencia y mejor calidad.
-Un ejemplo de uso en un HTML seria "<img src="../../public/img/algo.png" alt="Algo aparece en pantalla">"
-El atributo "alt" sirve para darle una descripcion a la imagen cuando esta no logra cargar, sirve para lectores de pantalla tambien.
