
 ==========================================
        DESCRIPCION DEL PROYECTO
 ==========================================

Farmacia La Esperanza App movil y sitio web, disenado para pedir medicamentos de forma concreat. Enfocada en adultos mayores con vision reducida y poco entendimiento de la tecnlogia.

 ==========================================
        ESTRUCTURA DE LAS CARPETAS
 ==========================================

```text
├── config/             # Configuraciones globales del sistema/servidor
├── controllers/        # Controladores que manejan la lógica de negocio
├── css/                # Hojas de estilo generales del sistema
├── database/           # Scripts de conexión, migraciones o respaldos de la BD
├── docs/               # Documentación general y registros del proyecto
│   ├── img/            # Capturas o imágenes de la documentación
├── models/             # Modelos de datos (comunicación con la base de datos)
├── public/             # Archivos accesibles públicamente por el navegador
│   ├── img/            # Multimedia estática (imágenes, logos)
│   ├── js/             # Archivos JavaScript del lado del cliente
│   ├── video/          # Contenido de video del sitio
├── routes/             # Definición de rutas y endpoints de la aplicación
├── static/             # Archivos estáticos organizados por perfiles (CSS/JS)
│   ├── css/            # Estilos del panel de control
│   │   ├── admin/      # Estilos para las vistas de administración
│   │   └── client/     # Estilos para las vistas de clientes
│   └── js/             # Scripts para el funcionamiento del panel
├── view/               # Plantillas y archivos HTML o de vistas
│   ├── admin/          # Vistas del panel de administración
│   ├── clients/        # Vistas destinadas al cliente
│   └── version-pc/     # Plantillas optimizadas para la versión de escritorio
├── .gitignore          # Archivo de exclusión de Git
└── README.md           # Documentación del proyecto
```

 ==========================================
        COMO ABRIR EL HTML INICIAL
 ==========================================

 Paso 1- Clonar el repositorio o descargarlo desde github.

 Paso 2- Ve a la carpeta views, ahi abre index.html con doble clic y se abrira la pagina en tu navegador.
